### Hi, I'm Shivang 👋

Software Engineer (MTS) at **TestMu AI (formerly LambdaTest)**, on the team behind **KaneAI**, an AI-native test authoring and management platform.
I work mostly in React, Next.js and TypeScript, care a lot about accessibility, and ship full-stack when the product needs it.

[Portfolio & blog](https://shivangramola.in) · [LinkedIn](https://www.linkedin.com/in/shivang-ramola007)

---

#### What I work on

- **KaneAI**: folder hierarchy for thousands of test modules, AI root-cause analysis for failed runs, enterprise-scale test-run filtering
- **Design system accessibility**: WCAG 2.1 AA, keyboard navigation and ARIA in our Primer-based component library
- Previously: Next.js 14 → 15 + TypeScript migration at Spyne.ai, real-time transit tracking (Socket.IO, Mapbox) at Hanging Panda
